# コントローラー お見積もりページ

GitHubのサーバー機能で動作するコントローラーのお見積もりページです。

## 機能

- 📦 **パーツ選択**: リポジトリに保存されたパーツリストから好きなパーツを選択
- 💰 **リアルタイム価格表示**: 選択したパーツに応じて価格がリアルタイムで更新
- 🔧 **状態別価格**: パーツの状態に応じた柔軟な価格設定
- ✨ **マイナス価格対応**: 状態により価格が下がる選択肢も用意

## パーツカテゴリ

### 1. スティック
- 新品 (+¥2,000)
- ややぐらつき(操作に影響なし) (±¥0)

### 2. スティック部タッチセンサー
- 反応あり (+¥2,000)
- 反応無し (±¥0)

### 3. バッテリー
- 8時間以上 (+¥3,000)
- 7時間半から7時間 (+¥2,000)
- 6時間半から7時間 (+¥1,000)
- 6時間から6時間半 (±¥0)
- 6時間未満 (-¥2,000)

### 4. コネクタ
- 新品(ジェネリック品) (+¥3,000)
- 中古品 (±¥0)

### 5. 外装
- 再塗装済み (+¥6,000)
- テカリなし (+¥6,000)
- テカリあり (+¥2,000)
- 塗装ハゲ少 (±¥0)
- 塗装ハゲ多 (-¥2,000)

### 6. 割れ
- 割れ厳禁 (±¥0)
- 割れ許容 (-¥2,000)

## 使用方法

### GitHub Pagesでの公開

1. リポジトリの Settings > Pages に移動
2. Source を「Deploy from a branch」に設定
3. Branch を選択（例: `main` または `claude/estimate-page-pricing-Xwhtm`）
4. Save をクリック
5. 数分後、`https://[ユーザー名].github.io/[リポジトリ名]/` でアクセス可能になります

### ローカルでの確認

```bash
# シンプルなHTTPサーバーを起動（Python 3）
python3 -m http.server 8000

# ブラウザで http://localhost:8000 を開く
```

## パーツリストのカスタマイズ

`parts.json` ファイルを編集することで、パーツや価格を自由にカスタマイズできます。

### 基本価格の変更

```json
{
  "basePrice": 15000,  // この値を変更
  "categories": [...]
}
```

### パーツの追加

```json
{
  "id": "new_part",
  "name": "新しいパーツ",
  "priceModifier": 1000,
  "description": "説明文"
}
```

## ファイル構成

```
.
├── index.html    # メインのお見積もりページ
├── parts.json    # パーツデータ（価格、説明など）
└── README.md     # このファイル
```
